---
name: memory:clear
description: Clear memories by scope
---

Clear memory content from specified scope.

## Arguments

- `$1`: Scope to clear - `user`, `project`, `local`, `auto`, or `all`

## Warning

This is a destructive operation. Always confirm with user before proceeding.

## Actions

1. Validate scope argument
2. Show files that will be deleted
3. Confirm with user (always required)
4. Delete specified memory files
5. Report what was cleared

## Usage

```
/memory:clear auto       # Clear auto-generated memories
/memory:clear local      # Clear local (gitignored) memory
/memory:clear project    # Clear project memory (requires confirmation)
/memory:clear all        # Clear all scopes (requires confirmation)
```

## Safety

- Never clears managed policy memory
- Project and user memory require explicit confirmation
- Auto memory can be regenerated by Claude
- Local memory is gitignored, safe to clear

## Scope Paths

| Scope | Path | Risk Level |
|-------|------|------------|
| user | `~/.claude/CLAUDE.md` | High - affects all projects |
| project | `./.claude/CLAUDE.md` | Medium - project-specific |
| local | `./CLAUDE.local.md` | Low - gitignored, personal |
| auto | `~/.claude/projects/{project}/memory/` | Low - regeneratable |

## Implementation

1. Use `getMemoryPaths()` to resolve paths
2. Use `AskUserQuestion` tool to confirm deletion
3. Use Bash `rm` command to delete files
4. Report success/failure for each file
